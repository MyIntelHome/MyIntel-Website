HomeAware is basic Wake & Well support. One motion sensor is not whole-home routine visibility. The standard pendant does not automatically detect falls. MDsense coverage is limited to each approved selected area. VPD2 adds voice help, not another area of fall detection. SleepSense requires one resident's compatible bed. Modifications and remote-vitals equipment are separately scoped. Professional response readiness remains disabled until arrangements are confirmed.

## Website structure

- Keep the existing /solutions route and canonical URL, with "Packages" as its navigation label.
- Use three visible package summaries with product photography. Exact device lists open using native details controls.
- Make the full feature comparison optional. On mobile, each feature shows the three packages as labeled rows without horizontal scrolling.
- Add a compact package introduction to the homepage. HomeCheck remains the primary entry; the installation enquiry goes to https://homecheck.myintelhome.com/?view=help.
- Preserve phone links, the founding homes waitlist, family/partner paths and the existing testimonial.
- No pricing, shop, recommended-package claim or competing purchase buttons.
