# MyIntel visual direction and image placement

## Direction
A warm editorial website, informed by the audience-first structure of mywisdom.io. Preserve MyIntel's identity and original copy. Use large photographs, short headings, quiet backgrounds and obvious Families / Partners paths. Keep HomeCheck as the consumer entry.
